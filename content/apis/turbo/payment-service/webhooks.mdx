          Receives webhook events from Stripe when payment events occur.


          **Supported Events:**

          - `payment_intent.succeeded` - Payment completed successfully, credits
          user's account

          - `charge.dispute.created` - Payment disputed, deducts credits if
          already credited


          **Security:** Webhook signature verification using Stripe webhook
          secret.


          **NOTE:** This endpoint is called directly by Stripe servers, not by
          clients.
