---
title: "Pricing a name"
description: "SDK for interacting with Turbo, a fast and efficient data upload service for Arweave"
---

Prices are quoted in both Turbo Credits (`winc`) and `mARIO` before you commit to anything:

```
GET /v1/arns/price/{intent}/{name}?type=lease&years=1
```

```typescript
const price = await turbo.getArNSPriceForName({
  intent: 'Buy-Name',
  name: 'my-name',
  type: 'lease',
  years: 1,
});

price.wincTotal; // <- charge or display THIS
price.winc;      // the name ONLY, excluding the ANT spawn surcharge
```

`wincTotal` is added by the SDK precisely so the correct field is the obvious
one: it resolves to `wincTotalWithAntSpawn` when a surcharge applies and to
`winc` when none does. Params are validated per intent, so a malformed request
throws a `ProvidedInputError` before any network call.

<Callout type="info">
  **Buying a name costs a bit more than the name.** Every purchase mints a
  fresh ANT for you on Solana, and Turbo fronts that account's rent. A small,
  flat cost-recovery surcharge covers it: the response carries
  `antSpawnSurchargeWinc` alongside `winc`, plus a convenience
  `wincTotalWithAntSpawn` (the two summed) so you don't have to do the
  arithmetic. **Quote the total** — a client that shows only `winc` will
  under-quote the purchase.
</Callout>

Only `buy-name` mints an ANT, so only `buy-name` carries the surcharge. Pricing an `Extend-Lease`, `Increase-Undername-Limit` or `Upgrade-Name` returns `winc` and `mARIO` alone.

## Fiat estimates

Add a `currency` query param to the price route and the response gains a `fiatEstimate`. Mind which field you quote:

- `fiatEstimate.paymentAmount` is the **bare** price, excluding the surcharge.
- `fiatEstimate.paymentAmountWithAntSpawn` is the **total**, and is the figure to show a customer buying a name.

`GET /v1/arns/quote/{method}/{address}/{currency}/{intent}/{name}` is the checkout-oriented route for topping up and buying in one step. Its `paymentAmount` is the real charge and already includes the surcharge.
