## Overview

A returned name is an ArNS name that has come back to the registry. This happens when a lease ends and its grace period runs out, or when the owner of a permanent name releases it. The name then goes to a Dutch auction: its price starts high and falls each day until someone buys it or it reaches the standard price. The falling premium stops squatters from grabbing a name the moment it expires, and lets the market set the price.

## Dutch auction mechanics

The auction lasts 14 days from the moment the name is returned. Its price is the normal registration fee for the purchase you choose (a lease of 1 to 5 years, or a permanent purchase) multiplied by a premium that falls in a straight line:

$$\text{multiplier} = 50 - \frac{49}{14} \times t$$

where $t$ is the number of days since the name was returned. For example:

| Days since return | Multiplier |
|-------------------|------------|
| 0 | 50x |
| 7 | 25.5x |
| 14 or later | 1x (standard price) |

The gateway operator discount applies on top of the auction price, as it does for a normal purchase.

## Revenue split

Who receives the payment depends on how the name entered the auction:

- Released by its owner: 50% goes to the [protocol balance](/glossary#protocol-balance) and 50% to the owner who released it. This rewards owners for giving up names they no longer need.
- Expired lease: 100% goes to the protocol balance. The previous lease holder receives nothing.

## How names enter the auction

### Lease expiration

A leased name has a 14-day grace period after its lease ends. During that time the owner can still extend the lease or upgrade the name to permanent. Once the grace period ends, anyone can move the name into the auction. [Crankers](/glossary#cranker) do this as routine cleanup.

### Voluntary release

The owner of a permanent name's ANT can release the name. Its registry record is removed and the auction starts at once. A leased name cannot be released this way.

## Query returned names

Use the SDK to check available returned names and their current auction price:

```typescript
import { ARIO } from '@ar.io/sdk';
import { createSolanaRpc } from '@solana/kit';

const ario = ARIO.init({
  rpc: createSolanaRpc('https://api.mainnet-beta.solana.com'),
});

// Get all active returned names
const returnedNames = await ario.getArNSReturnedNames({
  limit: 100,
  sortBy: 'endTimestamp',
  sortOrder: 'asc',
});

// Get a specific returned name
const name = await ario.getArNSReturnedName({ name: 'example' });

// Check current cost (includes auction premium)
const cost = await ario.getTokenCost({
  intent: 'Buy-Name',
  name: 'example',
  type: 'permabuy',
});
```
