## What ArNS does

An Arweave transaction ID is a 43-character string that is hard to remember and share. The Ar.io Name System (ArNS) gives your data a friendly name, such as `ardrive`, that works as a subdomain on any ar.io gateway that supports ArNS, for example `https://ardrive.ar.io`.

ArNS works like DNS, with three differences:

- No single company runs the registry. It lives on Solana, so anyone can check who owns a name.
- You pay for names in [ARIO](/learn/token). You can lease a name for 1 to 5 years or buy it permanently.
- A name points to data stored on Arweave, not to a server.

## How names resolve

When you register a name, you receive an Ar.io Name Token (ANT), an NFT on Solana that controls the name. Whoever holds the ANT sets its records. Each record points an undername to an Arweave transaction ID, so you can move the name to a new version of your app at any time.

Undernames use an underscore: `docs_ardrive.ar.io` asks for the `docs` record on the ANT behind `ardrive`, and `ardrive.ar.io` asks for its `@` record.

Every [gateway](/learn/gateways) resolves names on its own, by reading the name registry and the ANT's records from Solana:

```mermaid
sequenceDiagram
    accTitle: A gateway reads the name and its ANT records from Solana, then serves the data
    accDescr: A user requests docs_ardrive.ar.io from any gateway. If the gateway has no fresh cached answer, it looks up ardrive in the name registry on Solana to get the ANT address, then reads that ANT's records. It takes the transaction ID from the docs record and the TTL, which says how long it may cache the answer. It serves the data from its own cache, or fetches it from Arweave or other gateways first, and returns it with an X-ArNS-Resolved-Id header naming the transaction ID.

    participant User
    participant GW as Any ar.io gateway
    participant REG as Name registry on Solana
    participant ANT as ANT records on Solana
    participant DATA as Arweave and peers

    User->>GW: GET docs_ardrive.ar.io
    alt No fresh cached answer
        GW->>REG: Look up ardrive
        REG-->>GW: ANT address
        GW->>ANT: Read the ANT's records
        ANT-->>GW: Records by undername
        Note over GW: Take the docs record's tx ID and TTL
    end
    opt Data not in local cache
        GW->>DATA: Fetch data by tx ID
        DATA-->>GW: Data
    end
    GW-->>User: Content and X-ArNS-Resolved-Id header
```

If a gateway cannot read a name from Solana, it can ask a trusted gateway for the answer instead.
